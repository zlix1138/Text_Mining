# 통합 데이터셋 전달 가이드 (분석·스코어링 팀용)

> 한 줄 요약: **사람인(기준)+잡코리아(보완)** 공개 채용공고를 통합·정제한 데이터셋입니다.
> **일자리 "양"과 "질"은 데이터가 분리**되어 있으니, 반드시 아래 주의사항을 먼저 읽고 사용하세요.

---

## 0. 가장 먼저 알아야 할 3가지

1. **"질" 분석/스코어링은 `quality_jobs_clean.csv`(6,575행, 30컬럼)** 를 쓰세요.
2. **"양"(일자리 규모) 분석은 `quantity_region_jobgroup.csv`** 를 쓰세요.
   👉 **`quality_jobs_clean.csv`의 행 수로 일자리 양을 추정하면 안 됩니다.** 표본은 지역×직무군 균등 수집이라 양 비교용이 아닙니다.
3. 점수화(정규화·가중합)는 **아직 안 했습니다.** 질 피처는 원시 키워드 카운트이니, 스코어링 시 정규화하세요(§5).

## 2. `quality_jobs_clean.csv` 컬럼 명세

### (A) 식별·출처
| 컬럼 | 설명 |
|---|---|
| `job_id` | 고유 식별자. `SR######`=사람인, `JK######`=잡코리아 |
| `source` | 출처(`사람인`/`잡코리아`) — 출처 통제·비교용 |
| `url` | 공고 URL(검증·추적용) |

### (B) 공고 기본 정보
| 컬럼 | 설명 |
|---|---|
| `company_name`, `title` | 회사명·공고 제목 |
| `region` | 표준 지역명(10개 중 하나) — **분석 단위** |
| `region_detail` | 사이트 원문 근무지(상세) |
| `job_group` | 5개 직무군 중 하나 — **분석 단위** (미분류는 제외함) |
| `job_category_raw` | 사이트 원문 직종 태그(분류 검증용) |
| `career` | 경력(신입/경력무관/1년 이하/1~3년/3년 초과/기타·미상) |
| `education` | 학력 |
| `employment_type` | 고용형태(정규직/계약직함인턴/파견직/프리랜서/기타) |

### (C) 임금 — 연봉 환산 완료
| 컬럼 | 설명 |
|---|---|
| `salary_type` | 연봉/월급/시급/회사내규/면접후결정/비공개 |
| `salary_annual_min` | **연봉 환산 하한(만원)** — 아래 규칙 적용, 없으면 결측 |
| `salary_annual_max` | **연봉 환산 상한(만원)** |
| `salary_disclosed` | 연봉 환산 수치 존재 여부(1/0) |

> **연봉 환산 규칙**: 연봉=그대로, **월급=×12**, 그 외(시급·회사내규·면접후결정·비공개)는 **결측**. 이상치(1,000~20,000만원 밖) 18건은 오추출로 결측 처리. → 환산값 보유 **28.9%(1,897건)**, 중앙값 **약 3,380만원**.

### (D) 텍스트
| 컬럼 | 설명 |
|---|---|

| `q_work_time` | 근로시간/유연근무 키워드 수 | 0~n |
| `q_welfare` | 복지 키워드 수 | 0~n |

## 4. ⚠️ 분석·스코어링 필수 주의사항

**4-1. 임금 환산 한계**
- 연봉·월급만 수치가 있고(28.9%), 나머지(시급·회사내규·면접후결정·비공개)는 결측입니다. 임금 분석 시 **결측을 어떻게 다룰지**(제외 vs 대치) 명시하세요.
- **단시간 근로 주의**: `월급 124만원(주20시간)` 같은 파트타임도 ×12로 환산돼 있어 풀타임과 직접 비교 시 왜곡될 수 있습니다. `work_time`의 "주 N시간"으로 식별해 통제하세요.

**4-2. 양 ≠ 표본 행 수.** 표본은 지역×직무군 균등 수집이라 행 수로 일자리 규모를 비교하면 틀립니다. 양은 `sr_search_total_max` 컬럼을 사용.

**4-3. 사람인 양은 "하한 추정"**입니다. 직무군당 키워드 2개의 검색 모집단이 겹쳐 max를 썼습니다. 정밀 비교 시 `sr_keyword_detail` 참고.

**4-4. 잡코리아 양은 직무군 비교 불가** — 직무와 무관한 지역 총량만 있습니다.

**4-5. 출처 혼재 통제**: 사람인은 이미지형 JD가 많아 `raw_text`가 짧고(중앙값 532자), 잡코리아는 본문이 풍부합니다(중앙값 2,516자). 텍스트 기반 피처 비교 시 `source`로 통제하거나 출처별로 분석하세요.

**4-6. 공공기관(`is_public_sector=1`, 66건)** 은 채용방식·고용안정성이 민간과 다릅니다(EDA: 공공 정규직 50% vs 민간 88%). 스코어링 시 ① 포함/제외 민감도 분석, ② 공공·민간 분리 비교를 권장합니다.

**4-7. 제외된 공고**가 궁금하면 `integrated_labeled.csv`의 `exclude_reason`을 보세요. 제외 기준: 5직군 외(미분류)·청년부적합(경력3년초과/임원)·저정보(raw_text<100)·알바단기·지역미상·헤드헌팅. 기준을 바꿔 재필터링할 수 있습니다.

**4-8. `career`로 청년층 필터** 가능(신입/경력무관/1~3년). 명백한 청년 부적합은 이미 제외돼 있습니다.

## 5. 8개 차원 스코어링 매핑 가이드

> 권장 절차: 차원별 지표 산출 → **min-max 정규화(0~1)** → 가중합. 모든 질 피처는 **편익형(클수록 좋음)** 이라 역코딩 불필요.

| 기획서 차원 | 사용 컬럼/데이터 | 비고 |
|---|---|---|
| ① 임금 | `salary_annual_min/max`, `q_wage`, `salary_disclosed` | 수치는 결측 多 → 키워드+수치 병용, 결측 처리 명시 |
| ② 고용안정성 | `employment_stability` | 정규직=1 |
| ③ 근로시간·복지 | `q_work_time`, `q_welfare` | 필요시 `work_time` 텍스트 보강 |
| ④ 성장가능성 | `q_growth` | |
| ⑤ 일자리 양 | `quantity_region_jobgroup.csv`의 `sr_search_total_max` | 지역×직무군 단위 |
| ⑥ 직무 다양성 | `job_group` 분포(지역별) | 엔트로피/균형지수 등 계산 |
| ⑦ 청년친화성 | `q_youth_friendly`, `is_youth_friendly`, `career` | |
| ⑧ 정책 미스매치 | (외부 청년정책 데이터 필요) | 본 데이터셋 범위 밖 |

> ⑤·⑥은 **지역×직무군 집계 지표**, ①②③④⑦은 **공고 단위 피처**입니다. 종합점수를 지역×직무군 단위로 낼 경우 공고 단위 피처는 평균/비율로 집계하세요.

## 7. 데이터가 만들어진 과정 (요약)

원본 수집(사람인 5,500 + 잡코리아 5,500) → **5단계 통합** → **전달용 정리**:
1. 공통 스키마 정렬(`job_id` 부여) → 11,000
2. 미분류 재분류(정확도 우선) + 품질 필터(5직군 한정, 공공 플래그) → 6,885
3. 중복 제거(회사+제목 일치, 사람인 보존) → 6,575
4. 양/질 분리 + 질 피처 생성
5. 기초 EDA
